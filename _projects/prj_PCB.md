<div class="caption">
    I engineered a custom printed circuit board (PCB) using EAGLE CAD to interface with the piezoelectric materials. The primary function of the circuit is to acquire and amplify the generated input charge, enabling wireless telemetry to an external receiver. To achieve this wireless data transmission, I programmed an nRF52840 Bluetooth System-on-Chip (SoC) utilizing SEGGER Embedded Studio.
